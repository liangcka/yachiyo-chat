# Yachiyo Chat 文风与注释标准 (Prose Standard)

写出足够说明契约与意图的文字，彻底剔除推导过程、重复啰嗦与装饰性修辞。

---

## 1. 核心文风原则

- **清晰表达非显式契约**：注释说明“为什么这么做”（Rationale）、前置条件（Precondition）、副作用（Side-effects）与特殊边界条件，严禁复述代码控制流本身。
- **保留完整技术命题**：精简文字不能以牺牲事实完整性为代价。必须保留主体、触发条件、时序要求以及异常处理策略。
- **一处事实单一归属**：核心架构与长篇背景统一收拢于 Agent Notes 或顶级架构文档中，代码处保留精炼契约并以相对链接形式指向归档文档。

---

## 2. 各处文案的具体要求

- **公共函数与接口 JSDoc**：说明参数语义、返回值区别、可能抛出的异常类型及取消/超时机制。
- **内部复杂逻辑注释**：说明并发锁、状态机转换、DOM 尺寸计算等复杂计算的背后原因。
- **提示词（Prompts）**：提示词即行为规范。保持人设与技能指令精准，严禁产生歧义与废话填充。
- **UI 界面文案**：保持中日双语优雅、自然，符合月见八千代人设与现代聊天交互直觉。
