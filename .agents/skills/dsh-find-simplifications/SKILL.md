# Yachiyo Chat 代码精简指南 (Find Simplifications)

本技能帮助智能体识别 codebase 中维护成本高于其带来的价值的复杂代码，将其转化为事实充分的简化提案或重构。

---

## 1. 优质精简目标特征

- **无生产消费者**：公开的 helper、类型、状态字段或配置项仅在单测中被调用，无任何真实业务场景消费。
- **重复状态镜像**：多个 state 字段表达同一种衍生事实，可通过计算属性或单一来源代替。
- **手写造轮子**：手写的防抖、类型收窄或数组过滤已有通用工具库或原生现代 JS API（如 `structuredClone`、`URL.canParse` 等）支持。
- **推测性通用设计**：为了“未来可能用到”而编写的空接口、多层包装代理或复杂的抽象工厂。

---

## 2. 识别与精简工作流

1. **检索全局引用**：使用 `grep_search` 全局检索候选符号的所有出现位置，区分为生产调用与测试调用。
2. **评估删除收益与风险**：确认删除后不破坏现有 API 契约，且不影响 PC/桌面端的任何既有功能。
3. **保持移动端隔离**：精简范围仅限 Web/Desktop/Functions 代码，严禁触碰 `android/` 目录。
4. **验证回归**：精简完成后执行对应测试套件，证明行为完全不受损。
