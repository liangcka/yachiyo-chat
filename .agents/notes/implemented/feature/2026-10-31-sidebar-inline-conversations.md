# Agent Note: 侧边栏内嵌会话列表

Status: implemented

## Problem
查看或切换历史会话需要“打开侧边栏 → 点历史记录 → 在底部弹层中操作”两级跳转；历史弹层与侧边栏各自维护焦点陷阱与关闭动画，侧边栏本身只有入口按钮，信息密度低。

## Decision
- 侧边栏直接内嵌会话列表（`components/conversations/ConversationList.tsx`），独立的历史弹层组件移除。列表沿用原有的本地全文搜索、命中片段高亮、行内重命名与二次确认删除。
- 会话按最近更新时间分为“今天 / 昨天 / 最近 7 天 / 更早”，分组规则位于 `domain/conversation-groups.ts`，以本地自然日为界（构造日期而非减固定毫秒，避开夏令时错位），时钟回拨产生的未来时间归入今天。今天的会话显示时分，其余显示日期。
- 分组基准时间取打开侧边栏的时刻，由事件处理器写入状态，渲染保持纯净。
- 侧边栏排布：快捷操作（新建对话、压缩上下文）→ 会话列表 → 设置入口（双列，直达设置中心对应分页）→ 语言 → 账户操作。会话列表至少占约半屏并在内部滚动，滚到底后手势顺延给抽屉以露出下方分区。
- 选中会话时先收起侧边栏再切换；重命名与删除不关闭侧边栏。

## Alternatives considered
- **保留历史弹层并在侧边栏只显示最近几条**：仍需两套列表交互与焦点管理，且“查看全部”入口重新引入二级跳转。
- **会话列表与设置分区各自固定高度**：小屏手机上设置与账户分区会挤压列表到一两条，改为列表保底高度 + 抽屉整体滚动。

## Consequences
- 历史会话一次点击可达；搜索与列表共用一处实现。
- `UiCopy` 新增四个分组文案，移除已无入口的 `sessionSectionTitle`。
- 设置中心改为视口居中的弹层（`overlay--centered`）。页签保持单行分段，按面板宽度（容器查询，而非视口宽度）逐级收紧间距、隐藏图标，桌面端单列布局与 320px 窄屏下四个页签都完整可见。
- E2E 用例通过 `openConversationList` / `sideMenu` 辅助函数定位侧边栏内的“历史记录”区域。
