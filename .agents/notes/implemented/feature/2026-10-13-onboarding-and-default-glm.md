# Agent Note: 新手引导与默认 GLM 模型

Status: implemented

## Problem

首次使用时，用户缺少了解默认服务、模型配置和聊天功能的入口。本地模型设置与服务端 GLM 厂商元数据的默认型号也需要保持一致，预设列表不再提供 GLM-4.6 系列。

## Decision

用户首次通过认证后显示三步引导，依次介绍聊天、默认模型与配置入口、历史记录和记忆及联网搜索。引导支持上一步、下一步和跳过，设置面板提供重看入口，每次重看从第一步开始。

完成或跳过引导时，在现有 Dexie `settings` 表保存布尔键 `onboardingCompleted`。缺少该键或值不为 `true` 时视为尚未完成；读取失败仍显示引导，保存失败提示用户。该状态复用现有设置存储，不新增表、不升级数据库 schema。`clearAll()` 清除设置键后，下次启动重新显示引导。

本地未配置厂商时使用 `DEFAULT_PROVIDER_ID = "glm"`，GLM 默认和推荐型号均为 `glm-4.7-flash`，界面展示为 `GLM-4.7-Flash` 并标记免费。服务端 GLM 厂商默认型号与其一致，公共服务继续通过固定 GLM 配置调用该型号。

前端预设模型列表与免费型号列表移除 `glm-4.6`、`glm-4.6v-flash`。读取本地已保存的厂商和型号时保留原值；前端图片能力判断及后端兼容白名单保留旧视觉型号，后端继续接受旧型号请求。用户保存配置时，沿用现有预设校验规则，将不在预设列表中的型号回落为当前默认型号。

## Alternatives considered

- 在认证前展示引导：会遮挡访问入口，将引导安排在可使用聊天界面之后。
- 每次启动显示引导：重复打断使用；完成或跳过后保存状态，后续通过设置主动重看。
- 新增引导专用表或升级数据库版本：单个布尔设置无需独立 schema，复用设置表即可随清除本地数据重置。
- 删除后端全部 GLM-4.6 请求支持或自动迁移存量配置：会使已保存的文本、视觉配置失效或改变用户选择；仅收拢预设列表，并保留存量请求兼容。

## Consequences

- 引导状态仅保存在当前设备；清除本地数据后重新引导，不与服务端会话或其他设备同步。
- GLM-4.7-Flash 为纯文本模型，默认配置不开放图片输入；用户可主动选择支持图片的预设型号。
- 新默认值影响无配置时的设置草稿及后续保存，不覆盖已经激活的有效配置。
- 引导复用现有面板的焦点管理、关闭交互与动画，中日文案同步维护。
