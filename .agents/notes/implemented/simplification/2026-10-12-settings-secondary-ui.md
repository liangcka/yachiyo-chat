# Agent Note: 设置中心分段导航与只读记忆

Status: implemented

## Problem

设置中心沿用统一面板的分段导航与卡片布局。记忆设置的编辑、清除和撤销操作与只查看八千代记住内容的产品边界不符。

## Decision

- 四个设置分类沿用横向分段按钮，图标与标题并排，窄屏可横向滚动；方向键与 Home/End 切换分类，仅当前分类进入 Tab 顺序。切换时正文回到顶部。
- 聊天偏好沿用独立卡片与联网子项缩进，保留禁用联动；技能沿用卡片列表与文字开关，内容展开独立于启用状态。
- LLM 设置沿用自绘下拉菜单、推荐与识图徽章，字段顺序为厂商、API Key、模型，复用原有表单样式。首次挂载读取已保存配置；厂商切换隐藏密钥，保存回填保留成功反馈。页面卸载清理下拉菜单的外部点击监听。
- 记忆入口和分类标题统一为“记忆”（日语为“記憶”），正文使用原有记忆内容框样式只读显示，保留换行、长文本换行和空状态。设置中心不接收保存、历史或撤销回调，打开记忆页不读取变更记录。
- 自动整理与消息菜单的“记住这件事”仍通过已有模型流程生成记忆。数据层的历史记录与撤销能力保持兼容，设置中心不暴露这些操作。
- 设置面板与聊天偏好样式集中在 `settings.css`，技能卡片复用已有共享样式；中日文入口与空状态同步。

## Alternatives considered

- 禁用编辑器但保留操作按钮：仍会向用户提供无法使用的管理功能，只读文本更符合查看用途。
- 删除底层记忆历史与撤销能力：本次调整是设置界面的产品边界，不需要迁移已有存储或改变自动整理契约。

## Consequences

设置中心沿用原版布局，模型配置保持既有界面。用户可查看跨对话记忆，不能在设置中直接编辑、清除或撤销。存储结构、服务端协议与自动记忆生命周期保持兼容；撤回消息同步恢复本轮记忆的行为不受界面布局影响。
