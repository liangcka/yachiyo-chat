# Humanizer — 去 AI 味改写技能

## 技能定位

本技能用于改写文本，去除其中的「AI 味」，让文字读起来像真人写的。

- 适用场景：任何要求改写、润色、优化文风、去除 AI 痕迹的请求。
- 核心目标：改写后的文本通过「活人感」检验——读者无法察觉它出自 AI 之手。
- 原则：宁可朴素，不可做作；宁可具体，不可空泛；宁可短，不可绕。

## 四层自检体系

改写必须依次通过以下四层检验，任何一层不达标都不得输出。

### L1 硬性规则（零容忍）

扫描到即替换，不解释、不例外：

- **禁用句式**：「不是……而是……」「值得注意的是」「综上所述」「总而言之」「不难发现」「由此可见」。
- **套路结构**：「首先……其次……最后……」的三段式框架，改为自然衔接。
- **违规标点**：破折号滥用（一句里出现「——」超过一次即算滥用），改用逗号、句号或直接删掉插入语。

### L2 风格一致性

- **开头要具体**：第一句就进入具体的人、事、物、数字或场景，拒绝空泛铺垫（如「在这个信息爆炸的时代」）。
- **长短句交错**：连续三句等长即节奏僵化；长句拆短，短句连缀，制造呼吸感。
- **口语化**：书面腔（「进行了」「予以」「旨在」「系」）换成日常说法，但不过度网络化。

### L3 内容质量

- **观点要有细节支撑**：每个判断后面跟具体例子、数字或场景，删掉无支撑的断言。
- **比喻要有逻辑**：喻体和本体必须在关键属性上真正相似，不为了文艺而硬造比喻。
- **删除空洞大词**：「赋能」「闭环」「抓手」「底层逻辑」「生态」「颗粒度」「组合拳」——出现即删除或换成具体动作描述。

### L4 活人感终审

通读全文一遍，回答一个问题：**这段话像不像一个真人写的？**

判断参照：真人文笔有情绪起伏、有轻重取舍、偶尔口语跑偏、不会处处工整。不像，就回到 L1 重新过一遍，直到像为止。

## 处理流程

收到待改写文本后，按三步执行：

1. **扫描诊断**：统计禁用词命中数、套路句式数量、空洞大词数量，判定 AI 味程度——
   - 轻度（命中 ≤ 3 处）：只做局部替换和节奏微调。
   - 中度（命中 4–8 处）：逐句过 L1/L2，重组明显僵硬的段落。
   - 重度（命中 > 8 处或通篇模板腔）：整段重写，只保留原意和信息点。
2. **三步改写**：
   - 第一步「去泛化」：空泛表述换成具体信息。
   - 第二步「去书面化」：翻译腔、公文腔换成自然口语。
   - 第三步「回自然感」：调整节奏、加入自然衔接词，让全文有「说话的气口」。
3. **输出修改统计**：改写完成后附上简短统计——诊断等级、替换禁用词数量、调整句式数量、其他主要改动。

## 禁用词表

扫描到以下词条立即处理（替换建议供参考，以符合上下文为准）：

| 类别 | 禁用词条 | 处理方向 |
| --- | --- | --- |
| 堆叠副词 | 猛地、狠狠、仿佛、瞬间、稳稳 | 删除或换成更准确的动词，让动词自己发力 |
| 套路短语 | 稳稳地接住你、先说答案、掰开了揉碎了 | 直接删除，信息用平实句子说明 |
| 互联网黑话 | 底层逻辑、赋能、闭环、抓手、组合拳、颗粒度、生态 | 换成具体动作或删除 |
| 万能开头 | 在这个……的时代、随着……的发展 | 删除，直接从具体事实写起 |
| 总结腔 | 综上所述、总而言之、由此可见、不难发现 | 删除，结论直接说 |
| 对仗腔 | 不是……而是……、既……又……更…… | 拆成独立短句 |
| 滥用破折号 | ——（一句超过一次） | 改逗号、句号或删除插入语 |

## 输出要求

1. 先给改写后的完整文本。
2. 再附「修改统计」：诊断等级（轻/中/重度）、禁用词替换数、句式调整数、其他主要改动说明，控制在三行以内。
